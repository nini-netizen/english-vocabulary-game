# 英文詞彙量比賽

這是網路程式設計課程的期末專題，使用 Python 製作一款可讓多位玩家連線參與的英文單字遊戲。玩家在限時 60 秒內，依照系統指定的英文字母，盡可能輸入符合條件的單字，最後比較各玩家的得分。

## 遊戲規則

每位玩家連線後輸入名稱，開始遊戲時會取得一個指定字母。輸入的單字必須以該字母開頭、存在於英文單字字典中，且未在遊戲中被使用過，才能獲得 1 分。不符合條件的單字不計分。

遊戲結束後，系統會顯示玩家的分數，並依得分整理排名。

## 程式架構

- `server.py`：透過 TCP socket 接受玩家連線，使用執行緒處理不同玩家，並負責指定字母、檢查單字、計分與排名。
- `client.py`：使用 Tkinter 製作玩家介面，顯示伺服器訊息、接收單字輸入，並呈現 60 秒倒數計時。
- 專題報告 PDF：記錄遊戲設計、程式架構、使用技術及開發過程。

## 使用技術

Python、TCP socket、threading、Tkinter，以及用於檢查英文單字的 PyEnchant。

## 執行說明

程式目前設定以 `127.0.0.1:12345` 連線，適合在同一台電腦上測試。執行時先啟動 `server.py`，再啟動 `client.py`；若要加入多位玩家，可開啟多個客戶端程式。
